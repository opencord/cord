# Build System Variable Glossary

This documents every variable available in the build system.  The repos these
variables are used in are:

 - [cord](https://github.com/opencord/cord) (aka "build" when checked out)
 - [maas](https://github.com/opencord/maas)
 - [platform-install](https://github.com/opencord/platform-install)





## apt_cacher_name


DNS name for the apt-cacher-ng server used by compute nodes and LXC containers
on head node.



Default value:
```
apt_cacher_name: apt-cache

```

Used in:

- [platform-install/roles/apt-cacher-ng/defaults/main.yml](https://github.com/opencord/platform-install/tree/master/roles/apt-cacher-ng/defaults/main.yml#L20)
- [platform-install/roles/lxd-finish/defaults/main.yml](https://github.com/opencord/platform-install/tree/master/roles/lxd-finish/defaults/main.yml#L22)


## apt_cacher_port


Port number used for apt-cacher-ng.



Default value:
```
apt_cacher_port: 3142

```

Used in:

- [platform-install/roles/apt-cacher-ng/defaults/main.yml](https://github.com/opencord/platform-install/tree/master/roles/apt-cacher-ng/defaults/main.yml#L21)


## apt_ssl_sites


APT package sources are on HTTPS servers.  These bypass apt-cacher-ng, which
can't proxy SSL connections.



Default value:
```
apt_ssl_sites:
- apt.dockerproject.org
- download.docker.com
- butler.opencloud.cs.arizona.edu
- deb.nodesource.com
- artifacts.elastic.co

```

Used in:

- [platform-install/roles/apt-cacher-ng/defaults/main.yml](https://github.com/opencord/platform-install/tree/master/roles/apt-cacher-ng/defaults/main.yml#L23-L29)

Default value:


Used in:

- [platform-install/roles/xos-core-build/defaults/main.yml](https://github.com/opencord/platform-install/tree/master/roles/xos-core-build/defaults/main.yml#L20)

# CORD REST APIs

## XOS

A RESTful interface is available for configuring and controlling XOS. It is 
auto-generated from the set of [models](xos/README.md) configured 
into the POD manifest, and includes both core and service-specific models.

* [Core](https://guide.opencord.org/{{ book.branch }}/api/xos/ui/#/core)
* [Address Manager](https://guide.opencord.org/{{ book.branch }}/api/xos/ui/#/addressmanager)
* [vTR](https://guide.opencord.org/{{ book.branch }}/api/xos/ui/#/vtr)
* [vSG](https://guide.opencord.org/{{ book.branch }}/api/xos/ui/#/vsg)
* [vNoD Local](https://guide.opencord.org/{{ book.branch }}/api/xos/ui/#/vnodlocal)
* [vRouter](https://guide.opencord.org/{{ book.branch }}/api/xos/ui/#/vrouter)

# CORD REST APIs

## XOS

A RESTful interface is available for configuring and controlling XOS. It is
auto-generated from the set of [models](/xos/README.md) configured into the POD
manifest, and includes both core and service-specific models.

* [Core](/api\/#/core)
* [Address Manager](/api/#/addressmanager)
* [vTR](/api/#/vtr)
* [vSG](/api/#/vsg)
* [vNoD Local](/api/#/vnodlocal)
* [vRouter](/api/#/vrouter)
* [ONOS Service](/api/#/onos)
* [Fabric Service](/api/#/fabric)
* [Example Service](/api/#/exampleservice)
* [vEE](/api/#/vee)
* [vEG](/api/#/veg)
* [vnaas](/api/#/vnaas)
